Coding agents are at their best when you let them run on their own: accept edits, run the tests, try again. That's exactly when you don't want them near anything else. In worki, isolation isn't a plugin or a wrapper script. It's how every agent starts.

What an agent can reach

  • Its own worktree, at the same path as on your Mac
  • The parts of .git that committing needs
  • Tools you install into its environment
  • Tokens you hand it, kept in your Keychain

What it can't

  • Your home folder, with your SSH keys
  • Your browser profiles
  • Your other repositories and worktrees
  • Git hooks and config that later run as you
  • Your SSH agent, git credentials and GitHub login
  • Your environment variables, like API keys in your shell

Credentials reach an agent only when you hand it a token yourself. With isolation set to None, an agent runs as you and can reach what you can.

Nothing
  • Only the worktree. It appears at the same path as on your Mac. Git hooks and config stay read-only, so an agent can't plant anything that later runs as you.
  • A doctor for every backend. Plain-language checks with one-click fixes: create the agent user, start the sandbox daemon or Podman machine, build the image.
  • Agents ready inside. Agents are installed where they run the first time you start them, bring your settings and skills, and sign in with your subscription. Codex works too, as an experimental integration.
  • Secrets stay in your Keychain and reach sessions as environment variables.
  • Snapshots. Install a JDK or system packages once and save the sandbox or container; new worktrees of the project start from it.
  • No leftovers. Environments go away with their worktree or project.

Chat or terminal

Run Claude Code in its terminal, or as a chat worki draws itself.

Codex works both ways too, as an experimental integration.

  • See what it's doing. The step it's on, its background jobs, and how long the turn has run.
  • Switch while you talk. Model, effort and permission mode sit under the message box.
  • Attach text files and images, or paste screenshots. worki reads them itself, so they reach agents in any isolation.
  • Picks up where you left off. Conversations reopen with their history.
  • Continue on your phone. Turn on Remote Control and carry on in the Claude app or on claude.ai/code. What you send from there shows up in worki.
  • Your own shell below. Open a terminal next to the agent with ⌃`. Links in terminals open in your browser, sign-in links included.

From task to pull request

Commit, rebase, review and open the pull request without leaving the app.

  • Commit the files you pick, or let the agent write the commit messages.
  • Branch tab. How the branch stands against the branch it started from, with a safe Rebase and every file it touched.
  • Pull requests through the GitHub CLI: open one, follow its checks, and bring review comments back to the agent.
  • Review in place. Comment on any diff line and send the comments to the agent as one review.

Get started

  1. Download the latest release. It's a universal app, signed and notarized by Apple.
  2. Drag worki into Applications and open it.
  3. Add a repository, create a worktree, pick its isolation and start an agent. The doctor walks you through anything missing.
Download for macOS

For container isolation, install Docker Sandboxes, Docker Desktop or Podman. User Isolation needs nothing extra.

Build from source

You need Rust, Node 20 or later, pnpm and the Xcode command line tools.

git clone https://github.com/silvanfischer/worki.git
cd worki
./start_dev.sh
